# Экран для взаимодействия с теплицей на STM32

**Русский** · [English](README.en.md)

Экран для взаимодействия с теплицей на **STM32F103C8T6**: символьный LCD, круговое меню с энкодером, настройка интервалов и обратный отсчёт.

[![Макет с LCD и энкодером](media/preview.jpg)](media/demo.mp4)

[Видео демонстрации — 43 секунды, MP4 без звука](media/demo.mp4)

## Что реализовано

- Собственные функции управления LCD по 8-битному параллельному интерфейсу: инициализация, команды, текст и курсор.
- Выбор пунктов `PERIOD`, `DURATION`, `NEXT_IN`, `START` энкодером.
- Настройка периода в часах и длительности/задержки в минутах.
- Отображение обратного отсчёта и отмена кнопкой.
- Аппаратный опрос энкодера через TIM4 в режиме encoder interface.

## Мой вклад

Я самостоятельно разработал этот учебный проект: подключил LCD и энкодер, написал функции дисплея и логику меню/таймера, настроил периферию через STM32CubeMX. Используется STM32 HAL; готовая библиотека для LCD не использовалась.

## Подключения

| Сигнал | Вывод STM32 |
|---|---|
| LCD D0–D7 | PA0–PA7 |
| LCD RS / RW / E | PA8 / PA9 / PA10 |
| Кнопка энкодера | PB5 |
| Энкодер A / B | PB6 / PB7 — TIM4 CH1 / CH2 |

Таблица взята из исходников и конфигурации CubeMX. Точные модели платы/LCD/энкодера, питание, контраст и внешние подтяжки пока не задокументированы; это не полная монтажная схема.

## Структура и логика

- `Core/Src/main.c` — инициализация, выбор пункта меню, запуск циклов отсчёта.
- `MDK-ARM/lcd_functions.c` и `.h` — LCD, обработка кнопки, редактирование значений и отсчёт.
- `polivka.ioc` — конфигурация CubeMX.
- `MDK-ARM/polivka.uvprojx` — проект Keil µVision.
- `Drivers/` — включённые в сборку файлы STM32 HAL и необходимые заголовки CMSIS.

Положение энкодера берётся из счётчика TIM4. Отсчёт времени реализован программными задержками `HAL_Delay`; TIM4 обслуживает энкодер. Драйвер LCD сочетает вызовы HAL с прямой записью в GPIOA.

## Сборка

Используемые версии: **Arm Compiler 6.22**, **Keil.STM32F1xx_DFP 2.4.1**. В `.ioc` указан **STM32Cube FW_F1 V1.8.7**.

1. Клонировать репозиторий, сохранив структуру каталогов.
2. Открыть `MDK-ARM/polivka.uvprojx` в Keil µVision с Arm Compiler 6.22 и указанным device pack.
3. Выполнить **Rebuild**. Не требуется перегенерация CubeMX для сборки сохранённого проекта.

Выходные файлы создаются в `MDK-ARM/polivka/` и исключены из Git. В репозитории содержится необходимая для текущего проекта часть зависимостей, а не полная поставка Cube; для изменения конфигурации/перегенерации потребуется соответствующий пакет CubeMX.

## Известные ограничения

- При вращении энкодера назад от нуля редактируемое значение может перейти примерно к 16383; это видно в демонстрации. Границы редактирования не ограничены.
- `period` и `duration` имеют тип `uint8_t`, а редактор возвращает `uint16_t`: большие значения при сохранении усекаются.
- Блокирующий отсчёт включает задержки и время обновления LCD; точность длительных интервалов не измерена.
- Настройки не сохраняются после отключения питания.
